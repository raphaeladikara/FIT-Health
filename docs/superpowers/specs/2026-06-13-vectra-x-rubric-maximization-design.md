# VECTRA-X Rubric Maximization Design

## Goal

Raise the defensible competition score by addressing every material weakness in
`outputs/reports/project_rubric_reassessment_2026-06-13.md`. The target is full
rubric coverage, while keeping all scientific claims tied to freshly generated
evidence.

## Scientific Design

The outer multi-label split occurs immediately after target extraction. Leakage
screening, feature typing, category discovery, constant removal, and
missing-indicator selection are fit on the training partition only. A fitted
feature-frame transformer is saved with each deployable model and applies an
explicit unknown-category policy at inference.

Evaluation adds stratified bootstrap confidence intervals, repeated
multi-label cross-validation summaries, prevalence and clinical-rule baselines,
preprocessing/component ablations, threshold sensitivity, and decision-curve
net benefit. Rare-label support is displayed beside every estimate.

EDA adds Wilson prevalence intervals, center-by-label prevalence, and
missingness-by-center/label summaries. Every descriptive association is labeled
as non-causal and connected to a modeling consequence.

## Reporting Design

The final notebook includes a completed literature review with primary
methodological and authoritative clinical references, a related-work comparison
table, equations for calibration/conformal/triage logic, exact evaluation
provenance, and a limitations-first discussion of typhoid, yellow fever, and
center transfer.

The notebook calls VECTRA-X a competition prototype requiring prospective
validation. Conformal results are presented per label before aggregate
coverage, and calibration is described as label-dependent.

## Reproducibility And Privacy

Each run records package versions, timestamp, data/config checksums, git commit,
and execution mode. Cached artifacts are accompanied by a manifest.

Static web export is aggregate-only. Patient UUIDs, truth labels,
probabilities, and recommendations are not written to a public JSON bundle.

## Acceptance Criteria

- Train-only decisions are enforced by automated tests.
- Scientific tables are generated by the pipeline and consumed by the notebook.
- The notebook executes top-to-bottom without stored errors.
- Public web data contains no patient-level records.
- A fresh rubric reassessment maps evidence to every scoring component.

# Report Index and Provenance

The repository intentionally retains the complete Markdown improvement history.
Documents are classified below so intermediate findings are not mistaken for the
current scientific result.

## Canonical Current Reports

- `final_technical_report_sketch.md`: concise report aligned with the executed final
  notebook.
- `final_audit_resolution.md`: closure of the principal competition-audit findings.
- `limitations_and_ethics.md`: retained safety and deployment boundaries; the final
  notebook remains authoritative if wording differs.

## Audit and Improvement Provenance

- `project_full_competition_audit.md`: original full-repository competition audit.
- `blueprint_execution_summary.md`: implementation-stage execution record.
- `jury_qna_defense_bank.md`: presentation preparation material.
- `presentation_outline.md`: presentation planning material.

For any scientific claim, use this precedence order:

1. `notebooks/VECTRA_X_Final_Competition_Notebook.ipynb`
2. `outputs/tables/final_*.csv`
3. `outputs/reports/final_technical_report_sketch.md`
4. Historical reports for development context only
